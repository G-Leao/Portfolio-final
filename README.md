# Portfólio Pessoal — Gustavo Leão

Bem-vindo ao repositório do meu portfólio profissional.

Este projeto foi desenvolvido para apresentar minha trajetória como Desenvolvedor Front-end, reunindo informações sobre mim, minhas habilidades, tecnologias que domino e os principais projetos desenvolvidos durante minha formação em Engenharia de Software.

**Acesse o projeto:**  
https://gustavol.vercel.app

---

## Sobre o projeto

O objetivo deste portfólio é servir como minha apresentação profissional na área de tecnologia, demonstrando conhecimentos em desenvolvimento web moderno por meio de uma interface responsiva, organizada e intuitiva.

O site reúne:

- Apresentação profissional
- Tecnologias utilizadas
- Projetos desenvolvidos
- Currículo
- Informações de contato
- Interface moderna e responsiva

---

## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/G-Leao/seu-repositorio.git
```

Entre na pasta:

```bash
cd seu-repositorio
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Acesse no navegador:

```
http://localhost:5173
```
